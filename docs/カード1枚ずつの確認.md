# カード1枚ずつの確認

実装済み16枚を、1枚ずつ実機で確かめるための表。

---

## この表がある理由

最奥：風牙岩Lv1の不具合は、**効果の中身ではなく「いつ撃てるか」がずれていた**。

```
アタックステップに入っただけ（割り込みの窓は閉じている）
  → 【起動：フラッシュ】が撃ててしまう
  → しかも対象（アタックしているスピリット）がいないので何も起きない
```

自動テストは「効果が正しく働くか」は589本以上で見ているが、
**「その場面で出てよいか」は画面を見ないと分からない**。そこだけをこの表に集めた。

### 見つかっている不具合の型は3つ

| 型 | どう見えるか |
|---|---|
| **出てはいけない場面で出る** | 撃てるのに何も起きない／早すぎる場面で撃てる |
| **出るべき場面で出ない** | 条件を満たしているのに反応しない |
| **出るが盤面に届かない** | 「破壊した」と出るのにカードが残っている |

**どれも「押せるものが出ているか」を見れば分かる。** 効果の細かい数値は見なくてよい。

---

## 確かめなくてよいこと

自動テスト613本が毎回見ているので、手で確かめる必要はない。

- BPの境目（7000ちょうどは対象か、7001は対象外か）
- コアの個数、ドロー枚数、手札に戻る枚数
- 条件を満たさないときに何も起きないこと
- 破壊・消滅したカードが場から消えてトラッシュに行くこと
- 語彙調査（カードテキストの書き下し）との一致

**数え間違いを見つける必要はない。** 見るのは「押せるものが、正しい場面に出るか」だけ。

## だめだったときに教えてほしいこと

1. **左下の版表示に出ている文字**（そのまま）
2. **どのカードの、どの効果か**
3. **どの場面で**（メインステップ／アタック宣言の前後／割り込みの窓／相手のターン…）
4. **どうなったか** ── ここを次の3つで分けてもらえると原因が絞れる
   - 押すものが**出ない**
   - 出るけど押しても**何も起きない**
   - 起きたけど**盤面が変わっていない**

とくに「出るけど何も起きない」は、**出る場面が早すぎて対象がいない**ことが多い（風牙岩Lv1がそれだった）。

---

## 判断をお願いしたいこと

**［フラッシュ］しか持たないマジックを、自分のメインステップで使えてよいか。**

いまはフレイムハリケーンをメインステップで使えて、効果も出る。

```
メインステップで使用: 通った
相手の場（前）: グン＝ガタ(BP5000)
相手の場（後）: なし          ← 破壊された
リザーブ: 5 → 0              ← コストは払われた
```

バトルスピリッツの決まりでは「［フラッシュ］はフラッシュタイミングで使う」はずなので、
**メインステップでは弾くべきだと思う**が、ここは決まりの解釈なので確認したい。

- **弾くべき** → メインステップでは押せないようにする
- **今のままでよい** → 何もしない

なお ブレイククロー／オフェリングドロー は［メイン］も持っているので、この判断の影響を受けない。
