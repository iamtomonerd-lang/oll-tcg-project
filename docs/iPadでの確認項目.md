# iPadでの確認項目

公開したあと、iPadで実際に触って確かめるための表。

---

## この表がある理由

自動テストが通っているのに、実機で動かないことが2回あった。どちらも**私（Claude）の検証が、あなたの操作を再現していなかった**のが原因。

| 起きたこと | なぜ自動テストをすり抜けたか |
|---|---|
| 「デッキを組む」が見つからない | 検証が「デッキを変更」を押して近道し、起動直後の画面を通っていなかった |
| 押しても何も起きない（画面外に開いていた） | Playwrightの `click()` は要素を自動でスクロールして画面内に入れてから押すため、画面外のパネルでも操作できてしまう |

**自動テストは「機能が存在すること」は確かめられるが、「指で触って届くこと」は確かめきれない。** そこだけをこの表に集めた。

---

## 逆に、確かめなくてよいこと

以下は自動テスト589本が毎回見ているので、手で確かめる必要はない。

- カードの効果が正しく動くか（BPの境目、条件、Lv違い、〔ターン1回〕など）
- 40枚・同名3枚の判定
- 効果の解決順、割り込み、コアの移動
- ルールブックとの突き合わせ

**カードの挙動がおかしいと思ったら、それはテストの穴なので報告してほしい。** 手で確かめ続ける必要はない。

## ① まず最初に：どの版を見ているか

**これを最初にやる。** ここを飛ばすと、以降の結果が「古い版のせい」なのか「本当の不具合」なのか分からなくなる。

- [ ] 画面**左下**に版が出ている
  - 例：`8/2 23:04 版　デッキ構築の画面が…　119875b`
- [ ] その版が、私が「公開しました」と言った内容と一致している

一致していないとき：

- [ ] 左下の版表示を**押す** → 「新しい版があります」が出る
- [ ] 「更新する」を押す → 読み直されて、版が新しくなる

> それでも変わらないなら、Safariのタブを閉じて開き直す。ホーム画面から開いている場合は、アプリを一度終了してから開く。

## ② 開いた直後（いちばん見落としやすい）

**スクロールせずに**見えるかどうかが要点。

- [ ] 開くと「デッキを選んでください」の画面が出る（対戦相手を選ぶ画面ではない）
- [ ] 一覧の**いちばん上**に「🛠 デッキを組む」がある
- [ ] スクロールしなくてもそれが見えている

## ③ デッキ構築

- [ ] 「🛠 デッキを組む」を押すと、**その場で**デッキ構築の画面が出る
  - スクロールしないと出てこない、押しても何も起きない、は不具合
- [ ] カードが37種類並んでいる
- [ ] 赤いカード（26RSD01）には絵柄が出ている
- [ ] **＋を3回押すと止まる**（4枚目は押せない）
- [ ] −で減らせる
- [ ] **一覧の下のほうのカードで＋を押しても、先頭に戻らない**
- [ ] 「見本を入れる」で `40 / 40` になり、「この40枚で対戦」が押せるようになる
- [ ] 40枚のとき、どのカードも＋が押せない
- [ ] 「空にする」で0枚に戻る（確認が出る）
- [ ] 「← 戻る」でデッキ選択に戻れる

**指の当たり具合**（私には判断できない）

- [ ] ＋−が押しやすい大きさか。隣を誤爆しないか
- [ ] 一覧のスクロールが引っかからないか
- [ ] 文字が小さすぎないか

## ⑦ ホーム画面に置いたとき

**Safariで開いたときと挙動が違うことがある。** ここは特に見てほしい。

- [ ] 共有ボタン →「ホーム画面に追加」ができる
- [ ] アイコン（炎の宝玉）が出る
- [ ] そこから開くと**全画面**になる（Safariのアドレス欄が出ない）
- [ ] 全画面でも上の①〜⑥が同じように動く

- [ ] アプリを終了して開き直しても、組んだデッキ・配置が残っている

## だめだったときに教えてほしいこと

これがあると原因を絞れる。逆に、これが無いと私は推測で動くことになる。

1. **左下の版表示に出ている文字**（そのまま。これが最重要）
2. **どの画面で**（デッキ選択／デッキ構築／対戦中／モード選択…）
3. **何を押したか**
4. **何が起きたか**（何も起きない／エラーが出た／表示が崩れた）
5. **Safariで開いているか、ホーム画面のアイコンから開いているか**
6. 画面の写真があればなお良い

とくに「**何も起きない**」は、

- 押した反応が無い
- 反応はあるが何も表示されない
- 表示されたが画面の外にある

で原因がまったく違う。**画面を指で上下にスクロールしてみて、下のほうに出ていないか**を見てもらえると切り分けが早い。
