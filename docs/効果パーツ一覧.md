# 効果パーツ一覧（赤・紫）

実装済みのカード27枚（紫21枚・赤6枚）と、赤の語彙調査23枚から、
**カードテキストを「部品」に割った一覧**。

正式なカードが届いたら、テキストの一文をこの表から探し、
**同じ部品があれば呼ぶだけ。無ければ部品を1つ足して、この表に追記する。**

部品の置き場所：`src/ゲーム例/バトルスピリッツスタン/効果部品/`

| ファイル | 中身 |
|---|---|
| `いつ.ts` | ①きっかけ |
| `条件.ts` | ②〜なら |
| `誰を.ts` | ③対象の絞り込み |
| `何をする.ts` | ④効果の本体 |
| `代償.ts` | ⑤▶の左側 |
| `長さ.ts` | ⑥効いている長さ |
| `index.ts` | まとめて取り出す入口 |

カード側は `import { ... } from '../効果部品/index.js'` で使う。

## カード1枚の組み立て方

カードテキストは、いつも次の5つに割れる。

```
［Lv2］《真界放》『アタック時』コスト4以下の相手のスピリット1体を指定する。
 └①いつ  └②条件  └①いつ      └③誰を                  └④何をする

【起動：メイン】このネクサスを破壊する▶コスト3以下の相手のスピリット1体を指定する。
 └①いつ    └⑤代償                    └③誰を
```

| | 意味 | 例 |
|---|---|---|
| ① いつ | きっかけ | 破壊時／召喚時／アタック時／起動：メイン |
| ② 条件 | 〜なら | 真界放している／疲労状態の味方がいる |
| ③ 誰を | 対象の絞り込み | コスト4以下の相手のスピリット1体 |
| ④ 何をする | 本体 | コア1個をリザーブに置く |
| ⑤ 代償 | ▶の左側 | このネクサスを疲労させる |

**この5つを別々の部品にする。** そうすると「アタック時」×「真界放」×「コスト4以下の相手」×「コア1個剥がす」のように、
組み合わせでカードが書ける。同じ組み合わせが2枚あれば、2枚目は書かずに済む。

---

## 6分類すべてが資産

「④何をする が本体で、他は付属品」ではない。実データで数えると、
**一番使い回されているのは③（誰を）** で、上位は①③④にまたがる。

| 順位 | パーツ | 分類 | 使用枚数 |
|---|---|---|---|
| 1 | 相手のスピリットを選ぶ | ③誰を | **12** |
| 2 | コアを移す | ④何をする | 11 |
| 3 | BPを変える | ④何をする | 8 |
| 4 | 自分のスピリットを選ぶ | ③誰を | 7 |
| 5 | アタック中（持続） | ①いつ | 6 |
| 6 | 使用：フラッシュ | ①いつ | 5 |
| 7 | ドロー／真界放している／系統で絞る／常在 | ④②③① | 各4 |

さらに、**資産である理由は2種類ある。**「使い回し数」だけで価値を測ってはいけない。

| 資産である理由 | 意味 | 代表 |
|---|---|---|
| 使い回せる | 同じものを何度も書かずに済む | ③相手を選ぶ（12枚）、④コアを移す（11枚） |
| 作るのが難しい | 一度正しく作れば、二度と悩まない | ②真界放している、②このターンに〜、②消滅したなら |

②（条件）は使用枚数が1〜4枚と少ないが、**判定を間違えやすい部分がここに集中している。**
実際、このプロジェクトでこれまで直したバグは条件判定まわりだった。
⑤代償・⑥長さも同じで、数は少なくても一度作れば以後ずっと効く。

**結論：①〜⑥すべてを部品にする。** 分類ごとに扱いを変えない。

## ② 条件（〜なら）

| 部品 | 使用枚数 | 使っているカード |
|---|---|---|
| 真界放している | 8 | 紫03, 紫04, 紫07, 紫22, ゲン_ボー, グライファー, 飛傑レウファルス, 最奥：風牙岩, 赤2/8/12/22 |

**《真界放》の2つの規則**（取り違えやすいので分けて覚える）

| 規則 | 内容 | 関わるもの |
|---|---|---|
| 12-2-1-1-2 | Lv2コストのコアを置かなくても、ソウルコア1個でLv2になる | Lvへの**到達** |
| 12-2-1-1-3 | 《真界放》を持つカードがLv2のとき、真界放状態になる | 状態の**判定** |

ソウルコアが要るのは到達（12-2-1-1-2）のほうで、状態の判定（12-2-1-1-3）はLv2かどうかだけ。
通常コアだけでLv2にしたカードも等しく真界放状態になる。

真界放は自分自身の条件（`条件: 真界放している`）だけでなく、
他のカードの絞り込み（`カードフィルタ.真界放`）にも使える。
「真界放していない相手のスピリット」を対象にとる効果はこちらを `false` で指定する。
両方向の固定は `効果語彙/真界放.test.ts`。

| 疲労状態の味方がいる（系統・属性を指定できる） | 8 | 紫06, ロワミーク, 飛傑レウファルス, 浮遊岩域, 赤3/13/15/23 |
| 自分の手札がN枚以下 | 2 | ムーシャッコ, 赤1 |
| このターンに自分のライフが減っていた | 2 | 紫16, 赤19 |
| （直前の対象が）消滅したなら | 1 | 紫20 |
| そうしたなら（直前の処理が成功したなら） | 1 | 紫13 |
| 〔ターン1回〕 | 2 | グライファー, 最奥：風牙岩, 赤7/12 |

**複数の条件を AND で結合**

複数の条件が必要な効果は `かつ()` で組み合わせる。

```typescript
// 「手札が5枚以下 かつ 真界放している」
条件: かつ(手札がN枚以下(5), 真界放している)
```

条件はいくつでも結合できる。

```typescript
// 3つ以上の条件を結合
条件: かつ(条件A, 条件B, 条件C)
```

## 使い方（正式なカードが1枚届いたとき）

1. カードテキストを、上の①〜⑥に割る
2. それぞれ、この表に同じ部品があるか探す
3. **全部あれば、組み合わせて書くだけ**（新しい処理は書かない）
4. 無い部品があれば、それだけ作ってこの表に1行足す
5. テストを流す。全部通れば、既存のカードを壊していない

## 部品化で消えた重複

| 重複していた内容 | 枚数 | 部品化前 | 部品化後 |
|---|---|---|---|
| 相手を選ぶ→コアをリザーブに置く | 10 | 同じ11行が10か所にコピペ | `それのコアをリザーブに置く({ 個数: 1, ソウルコアは除く: true })` |
| 選ぶ→BPを変える | 3 | 同じ形が3か所 | `それのBPを変える(2000, このターン中)` |
| 自分自身のBP+2000（真界放・アタック中） | 3 | 紫03・紫07・ゲン_ボーが別々に記述 | 3枚とも同じ2行 |

カードデータ27枚から、生の効果記述（`{ コア移動: ... }` など）は全て無くなった。

### 部品化して壊れていないことの確認

部品化の前後で、**27枚すべてが生成する効果データが完全に一致する**ことを突き合わせて確認した
（キーの有無・値ともに同一）。加えてテスト335本が通る。

つまり部品化は書き方だけを変えたもので、カードの動きは1つも変わっていない。
