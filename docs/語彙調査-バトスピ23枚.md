# 語彙調査 — バトルスピリッツ実カード23枚

実物のカードテキスト23枚を語彙分解し、必要なプリミティブを実データから確定した記録。

## 最重要の発見：語彙は飽和する

カードを1枚ずつ順に読み、**そのカードで初めて登場した語彙**を数えた結果：

| カード番号 | 新規語彙 | 累計 |
|---|---|---|
| 1〜6 | 4, 3, 7, 7, 4, 4 | 29 |
| 7〜12 | 6, **0**, 1, 2, 3, 1 | 42 |
| 13〜18 | 2, 2, 4, 1, 1, 1 | 53 |
| 19 | 2 | 55 |
| **20〜23** | **0, 0, 0, 0** | **55** |

- 前半12枚で 42個（1枚あたり3.5個）
- 後半11枚で 13個（1枚あたり1.2個）
- **最後の4枚は新規語彙ゼロ**

カード20・21・22・23 は、すでに登場した語彙の**値違い**でしかない。

### 具体例：4枚が同じ形

| # | テキスト | 差分 |
|---|---|---|
| 3 | 疲労状態の自分の赤のスピリットがいるなら、BP**3000**以下の相手のスピリット1体を破壊 | 条件=属性赤 |
| 8 | 《真界放》BP**3000**以下の相手のスピリット1体を破壊 | 条件=真界放 |
| 20 | BP**7000**以下の相手のスピリット1体を破壊 | 条件なし |
| 23 | 疲労状態の**系統風牙**の自分のスピリットがいるなら、BP**5000**以下の相手のスピリット1体を破壊 | 条件=系統 |

**4枚 = 1つのデータ形 + 値**。現行方式なら4枚で2,400行書くことになる。

同様の反復：
- カード4 と 22（デッキオープン→系統フィルタ→手札→残り破棄）：枚数違いのみ
- カード5 と 21（トラッシュのコアをN個まで置く）：対象が自身か選択かのみ
- 「疲労状態の自分の赤のスピリットがいるなら」は 3・13・15 の3枚に登場

## インタプリタの形を決める3つの要求

23枚から、インタプリタが**必ず持たねばならない機構**が3つ確定した。

### 1. 対象選択の中断・再開（最優先）

「指定する／指定できる」を含むカードは **23枚中14枚（61%）**。過半数。

プレイヤー入力待ちで処理が中断し、選択後に**同じ処理列の続きから再開**する必要がある。
現在サーバーに手書きした `保留中の効果` を、汎用の1箇所に集約して解決する。

### 2. 中間スコープ（カード群の一時変数）

カード4・17・22 の「デッキの上からN枚をオープンする。**その中の**〜を手札に加える。**残りは**〜」は、
オープンしたカード群を一時的に保持し、選択分と残りに分割する機構を要求する。

処理は「1回の操作」ではなく、**状態を持つ処理列**である必要がある。

### 3. 値の遅延評価（条件付き置換）

カード19「BP7000以下…**このターンに自分のライフが減っていたなら、かわりに指定するBPを10000以下にする**」は、
フィルタの数値がゲーム状態に依存して決まる。

数値を定数ではなく**評価式**として扱う必要がある。

## データ形式の検証

上記の語彙で23枚が実際に書けるかを検証した。

### カード3・8・20・23（同一形、値違い）

```typescript
// 3
{ Lv: [1,2], トリガー: '召喚時',
  条件: { 存在: { 場:'自分', 種別:'スピリット', 属性:'赤', 状態:'疲労' } },
  処理: [ { 選択:{ 場:'相手', 種別:'スピリット', BP以下:3000, 数:1 } },
          { 破壊:'選択' } ] }

// 23（条件のフィルタと BP値だけ違う）
{ Lv: [1,2], トリガー: '召喚時',
  条件: { 存在: { 場:'自分', 種別:'スピリット', 系統:'風牙', 状態:'疲労' } },
  処理: [ { 選択:{ 場:'相手', 種別:'スピリット', BP以下:5000, 数:1 } },
          { 破壊:'選択' } ] }

// 20（条件なし）
{ Lv: [1,2], トリガー: '召喚時',
  処理: [ { 選択:{ 場:'相手', 種別:'スピリット', BP以下:7000, 数:1 } },
          { 破壊:'選択' } ] }

// 8（真界放条件、アタック時）
{ Lv: [2], 条件: { 真界放:true }, トリガー: 'アタック時',
  処理: [ { 選択:{ 場:'相手', 種別:'スピリット', BP以下:3000, 数:1 } },
          { 破壊:'選択' } ] }
```

```typescript
  コスト: [ { 選択:{ 元:'自分手札', 系統:'風牙', 数:1 } },
            { 破棄:'選択' } ],

```

### カード15（逐次＋途中条件分岐）

```typescript
{ 種別:'使用', タイミング:'メイン',
  処理: [
    { 選択:{ 場:'相手', 種別:'ネクサス', 真界放:false, 数:1 } },
    { 破壊:'選択' },
    { もし:   { 存在:{ 場:'自分', 種別:'スピリット', 属性:'赤', 状態:'疲労' } },
      ならば: [ { コア移動:{ 元:'自分トラッシュ', 除外:'ソウルコア', 数:1, 先:'自分リザーブ' } } ] },
  ] }
```

### カード19（値の遅延評価）

```typescript
{ 種別:'使用', タイミング:'フラッシュ',
  処理: [
    { 変数:{ 名:'BP上限', 既定:7000,
             もし:{ ライフ減少:'このターン' }, ならば:10000 } },
    { 選択:{ 場:'相手', 種別:'スピリット', BP以下:'$BP上限', 数:1 } },
    { 破壊:'選択' },
  ] }
```

**23枚すべてがこの形式で表現できることを確認した。**
