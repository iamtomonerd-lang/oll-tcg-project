# 配置モードの使い方

対戦画面の並びと大きさを、**コードを触らずに画面上で決める**ための仕組み。

## 使いかた

1. `npm run server` でサーバーを起動し、ブラウザで対戦を始める
2. 画面の右下にある **⚙ 配置** を押す
3. 動かしたいブロックをドラッグする。右下の四角を引っぱると大きさが変わる
4. 気に入ったら **保存** を押す。次に開いたときからその配置になる

元の並びに戻したいときは **既定に戻す**。

## 動かせるもの

| ブロック | 中身 |
|---|---|
| 相手の情報バー | 相手の名前・ライフ・リザーブ・デッキ・トラッシュ |
| 相手の手札 | |
| 相手のフィールド | |
| ターン表示 | 「あなたのターン」とステップ終了ボタン |
| 自分のフィールド | |
| 自分の情報バー | 自分の名前・ライフ・リザーブ・デッキ・トラッシュ |
| 自分の手札 | |

カードの大きさは、パネルの **カード** のつまみで変える（縦横比は保たれる）。

## 細かく合わせる

| やりたいこと | 操作 |
|---|---|
| おおまかに置く | ドラッグ |
| 大きさを変える | 右下の四角をドラッグ |
| 0.5%ずつ動かす | 矢印キー |
| 0.1%ずつ動かす | Shift + 矢印キー |
| 大きさを少しずつ変える | Ctrl + 矢印キー |
| 吸着させない | Alt を押しながらドラッグ |
| 数字でぴったり決める | パネルの 左・上・幅・高さ に入力 |

**ブロックが重なって掴めないとき**は、パネルの一覧からそのブロックを選ぶ。
選んだブロックは一番手前に来るので、必ず操作できる。

パネル自体が邪魔なときは、見出し（「配置モード」の帯）を掴んで動かすか、
右の **▾** でたたむ。

## 数値の意味

位置と大きさは **盤面に対する％**。ピクセルではないので、
画面の大きさが変わっても比率が保たれる。

ブロックは盤面の内側にしか置けない。画面の外に出せてしまうと、
掴む場所ごと消えて戻せなくなるため。

## 保存されるもの

保存すると `public/レイアウト.json` が書かれる。中身はこの形。

```json
{
  "版": 1,
  "カード幅": 108,
  "ブロック": {
    "相手情報": { "x": 0.8, "y": 1.3, "w": 98.4, "h": 5.9 }
  }
}
```

このファイルがあると、次にゲームを開いたときに自動で当たる。
チームで同じ配置を使いたい場合は、このファイルをコミットする。

## 調整できるブロックを増やしたいとき

1. `public/index.html` の対象のタグに `data-layout-id="なまえ"` を足す
2. `public/layout.js` の冒頭にある `ブロック定義` に1行足す

```js
{ id: 'なまえ', 名前: '一覧に出す表示名', セレクタ: '#そのタグのid' },
```

ここに1行足せば、配置モードで動かせるようになる。
